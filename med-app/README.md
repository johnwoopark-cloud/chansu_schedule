# 우리집 복약 앱 (med-app)

가족(엄마·아빠·아이)이 함께 쓰는 복약·상담대비 기록 웹앱입니다.
Google Apps Script 웹앱 + 구글 스프레드시트로 동작하며, 서버 비용은 없습니다. 알림(푸시) 기능은 없습니다.

설치는 [설치가이드.md](설치가이드.md)를 따라 하세요.

## 기능
- **오늘의 약**: 시간대별로 약을 보여 주고 [먹었어요]로 기록. 누가 몇 시에 기록했는지 가족 모두에게 보임
  - 같은 회차를 두 번 기록하려 하면 경고 (실수로 기록했으면 취소 가능)
  - **지난 날짜 기록**: ‹ › 로 최근 7일까지 이동해서 깜빡한 복용(예: 어제 저녁)을 나중에 기록. 시트에는 `나중에 기록`으로 표시
- **필요할 때 먹는 약** (두통약 등): 이유(두통/발열/기타)와 함께 기록, 최소 복용 간격보다 빠르면 경고
- **약 여러 개** 추가·수정·복용 중단, 남은 양 자동 차감, 7일분 미만이면 주황색 표시
- **상담대비 기록** (진료 상담 때 보여 줄 증상 기록): 날짜·시각, 지속 시간, 종류, 발생 상황, 전조 증상, 당시 복약, 메모
  - `index.html`의 `SHOW_SEIZURE`를 `false`로 바꾸면 숨김 (서버 기능과 시트는 그대로)
- **달력**: 날짜별 복약 완료 여부와 상담대비 기록 표시, 이번 달 복약률·상담대비 기록 수·필요 시 복용 수, 날짜별 상세와 "이 날 복약 기록하기"

## 구조
```
가족 폰 (홈 화면 아이콘 = 웹앱)
          │ google.script.run
          ▼
   Apps Script (Code.gs)
          │
   구글 스프레드시트: 약목록 / 복약기록 / 상담대비기록
```

- **접속**: 비밀 키 방식. 가족 주소(`웹앱URL?k=키`)를 한 번 열면 키가 그 폰 브라우저에 저장되고, 이후에는 키 없는 주소로 열림. 모든 API가 키를 확인함. 앱 안에서 로그아웃 가능, `rotateKey()`로 전체 차단 가능
- **비밀 값**: 비밀 키(`APP_KEY`)는 코드가 아니라 스크립트 속성에만 저장됨
- **외부 전송 없음**: 기록은 이 스프레드시트에만 저장되고 다른 서비스로 보내지 않음. 예전 버전의 15분 알림 트리거는 `checkReminders`가 실행될 때 스스로 지워짐

## 파일
| 파일 | 내용 |
|---|---|
| `Code.gs` | 서버 코드: API, 관리용 함수(`setup`, `showLinks`, `rotateKey`) |
| `index.html` | 화면 (HTML/CSS/JS 한 파일) |
| `appsscript.json` | 시간대(서울), 웹앱 설정, 권한 범위 |
| `test/harness.js` | Apps Script 서비스(시트, 속성, 시간 등)를 흉내 내서 Node에서 `Code.gs`를 실행 |
| `test/test.js` | 서버 로직 테스트 |
| `test/ui.js` | 브라우저(Playwright)로 화면을 열어 등록→약 추가·수정→복용→지난 날짜 기록→상담대비 기록→달력→로그아웃까지 실행 |

## 테스트
```bash
node med-app/test/test.js
node med-app/test/ui.js [스크린샷 폴더]   # playwright 필요
```

테스트는 흉내 낸 환경에서 돌아가므로, 실제 구글 환경에서만 확인할 수 있는 부분(권한 승인, 배포 주소, 폰 브라우저 저장 공간)은 설치 후 직접 확인해야 합니다.
