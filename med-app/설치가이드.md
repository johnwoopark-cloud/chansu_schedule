# 우리집 복약 앱 설치 가이드

처음 한 번만 하면 됩니다. **컴퓨터(PC)에서 하는 것을 추천**합니다. 30분 정도 걸려요.

준비물
- 관리자 구글 계정 1개 (엄마나 아빠 계정)
- 가족 폰 (엄마, 아빠, 아이)

---

## 1단계. 스프레드시트 만들기 (관리자, PC)

1. 관리자 계정으로 로그인한 뒤 https://sheets.new 를 엽니다.
2. 왼쪽 위 제목을 **우리집 복약 기록**으로 바꿉니다.
3. 이 시트는 **아무에게도 공유하지 않아도 됩니다.** 가족은 앱으로만 씁니다.

## 2단계. 코드 붙여넣기

1. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 누릅니다. 새 탭이 열립니다.
2. 왼쪽의 **⚙ 프로젝트 설정**에서
   - **"편집기에서 'appsscript.json' 매니페스트 파일 표시"**를 체크합니다.
   - 시간대가 **(GMT+09:00) 서울**인지 확인합니다.
3. 왼쪽의 **< > 편집기**로 돌아와서 파일 3개를 채웁니다.

| 편집기의 파일 | 붙여넣을 내용 (이 저장소의 파일) |
|---|---|
| `Code.gs` (원래 있음) | `med-app/Code.gs` 전체 |
| `appsscript.json` (원래 있음) | `med-app/appsscript.json` 전체 |
| `index.html` (새로 만들기) | `med-app/index.html` 전체 |

   - `index.html` 만들기: 파일 옆 **＋ → HTML** → 이름에 `index`라고만 입력합니다(`.html`은 자동으로 붙어요).
   - 원래 들어 있던 내용(`function myFunction() {}` 등)은 **모두 지우고** 붙여넣습니다.
4. 💾 저장(Ctrl+S)을 누릅니다.

## 3단계. setup 실행 (권한 승인)

1. 위쪽의 함수 선택 칸에서 **setup**을 고르고 **▷ 실행**을 누릅니다.
2. "승인 필요" 창이 뜨면 **권한 검토 → 관리자 계정 선택**을 누릅니다.
3. "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음)**을 누르고 **허용**합니다.
   - 내가 직접 만든 스크립트라서 나오는 경고입니다. 요청 권한은 이 시트 읽기·쓰기, 외부 알림 전송(ntfy), 15분 알림 예약 세 가지뿐입니다.
4. 아래 실행 로그에 "설정 완료"가 보이면 성공입니다. 시트에 **약목록 / 복약기록 / 경련기록** 탭이 생깁니다.

## 4단계. 웹앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. ⚙(유형 선택) → **웹 앱**을 고릅니다.
3. 다음처럼 설정합니다.
   - 설명: `우리집 복약`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누르고 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
5. 그 URL을 브라우저에서 **한 번 열어 봅니다**. "등록이 필요해요" 화면이 나오면 정상입니다.

> "모든 사용자"로 해도 비밀 키가 없으면 아무 기록도 보거나 쓸 수 없습니다.

## 5단계. 가족 주소와 알림 토픽 확인

1. Apps Script 편집기에서 함수 **showLinks**를 골라 **▷ 실행**합니다.
2. 실행 로그에 다음 두 가지가 나옵니다. 메모해 두세요.
   - **가족 주소**: `https://script.google.com/macros/s/.../exec?k=비밀키`
   - **ntfy 토픽**: `fam-med-xxxxxxxxxxxx`

> ⚠️ 가족 주소는 **비밀번호와 같습니다.** 가족 단톡방이나 각자의 '나와의 채팅'으로만 보내고, 다른 곳에 올리지 마세요.

## 6단계. 가족 폰마다 알림 앱(ntfy) 설치

각 폰에서:
1. **ntfy** 앱을 설치합니다. (Play 스토어 / App Store에서 "ntfy" 검색. 개발자 Philipp Heckel)
2. 앱에서 **＋(구독 추가)**를 누르고 **토픽 이름**에 5단계의 ntfy 토픽을 입력합니다. 서버는 기본값(ntfy.sh) 그대로 두고 **구독**합니다.
3. 안드로이드: 앱이 "배터리 최적화 제외"를 물으면 **허용**합니다. 그래야 알림이 늦지 않아요.
4. 모든 폰에서 구독을 마친 뒤, 관리자가 Apps Script 편집기에서 **testNtfy**를 실행합니다. 모든 폰에 "알림 시험" 알림이 오면 성공입니다.

## 7단계. 가족 폰마다 앱 등록 + 홈 화면에 추가

각 폰에서:
1. **가족 주소**(비밀 키가 붙은 주소)를 엽니다.
2. "이 폰은 누가 쓰나요?"에서 **엄마 / 아빠 / 아이** 중 하나를 누릅니다.
3. 파란 안내 상자의 **[홈 화면용 주소 열기]**를 누릅니다. 비밀 키가 빠진 주소가 열립니다.
4. 그 화면에서 홈 화면에 추가합니다.
   - **안드로이드(크롬)**: 오른쪽 위 ⋮ → **홈 화면에 추가**
   - **안드로이드(삼성 인터넷)**: 아래 ≡ → **현재 페이지 추가 → 홈 화면**
   - **아이폰(사파리)**: 아래 공유 버튼 □↑ → **홈 화면에 추가**
5. 홈 화면의 아이콘으로 열어서 "오늘의 약" 화면이 나오면 끝입니다.

## 8단계. 약 등록

아무 폰에서나 **[+ 약 추가]**로 약을 등록하면 모든 가족 폰에 같이 보입니다.
- **정해진 시간**: 매일 먹는 약. 복용 시각을 여러 개 고를 수 있어요.
- **필요할 때**: 두통약처럼 그때그때 먹는 약. **최소 복용 간격은 의사·약사가 안내한 값**으로 고르세요.
- **현재 남은 양**은 숫자와 단위로 적어 주세요(예: `60ml`, `30정`). 먹을 때마다 1회 용량만큼 자동으로 줄어듭니다.

# 사용하면서

## 알림 규칙 (지금 설정)
- 복약 예정 시각 **30분 뒤** 기록이 없으면 1차 알림, **60분 뒤** 2차 알림(긴급)
- **밤 11시 ~ 아침 7시**에는 알림을 보내지 않음
- 남은 약이 **7일분 미만**이면 아침 9시 이후 하루 한 번 알림
- 경련을 기록하면 가족 모두에게 바로 알림
- 알림은 15분마다 확인하므로 **최대 15분 늦게** 올 수 있어요

바꾸고 싶으면 `Code.gs` 맨 위의 `CONFIG` 값을 고친 뒤 아래 "코드를 고쳤을 때"대로 다시 배포하세요.

## 시트에서 직접 고치는 것
| 하고 싶은 일 | 방법 |
|---|---|
| 약을 새로 타 왔음 | `약목록` 탭의 **남은양** 숫자를 새 양으로 바꾸기 |
| 약 이름·용량·시각 바꾸기 | `약목록` 탭에서 해당 칸 수정 (복용시각은 `08:00,20:00` 처럼 쉼표로) |
| 약을 그만 먹음 | `약목록` 탭의 **사용중**을 `N`으로 |
| 잘못된 기록 지우기 | `복약기록` / `경련기록` 탭에서 그 행 삭제 |
| 진료 때 보여 주기 | 시트를 그대로 보여 주거나 **파일 → 다운로드 → Excel** 또는 **인쇄** |

> 약목록의 **ID** 칸은 바꾸지 마세요. 기록과 연결되는 값입니다.

## 코드를 고쳤을 때 (주소 유지)
1. Apps Script 편집기에 새 코드를 붙여넣고 저장
2. **배포 → 배포 관리 → ✏️(수정) → 버전: 새 버전 → 배포**

> **새 배포**를 누르면 주소가 바뀌어서 모든 폰을 다시 등록해야 합니다. 꼭 **배포 관리**에서 수정하세요.

## 폰을 바꿨을 때
기록은 시트에 있으니 그대로입니다. 새 폰에서 **6단계(ntfy 구독)**와 **7단계(가족 주소로 등록)**만 다시 하면 됩니다. 예전 폰은 앱 설정(⚙)에서 **이 폰에서 로그아웃**을 누르거나 초기화하세요.

## 폰을 잃어버렸을 때
1. Apps Script 편집기에서 **rotateKey**를 실행합니다. 비밀 키가 바뀌고 **모든 폰이 로그아웃**됩니다.
2. 로그에 나온 **새 가족 주소**로 남은 폰들을 다시 등록합니다(7단계).
3. 알림 토픽까지 바꾸고 싶다면: ⚙ 프로젝트 설정 → 스크립트 속성에서 `NTFY_TOPIC`을 지우고 `setup`을 다시 실행한 뒤, 모든 폰에서 새 토픽을 구독합니다.

## 문제 해결
| 증상 | 해결 |
|---|---|
| 홈 화면 아이콘으로 열면 계속 "등록이 필요해요"가 나옴 | 그 폰의 브라우저가 저장 공간을 지웠어요. 가족 주소를 다시 열어 등록하세요. 계속되면 가족 주소 자체를 홈 화면에 추가해도 됩니다(대신 앱 안 로그아웃 효과가 약해짐). |
| "시트가 없어요" 오류 | 관리자가 `setup`을 실행하지 않았거나 탭 이름을 바꿨어요. 탭 이름을 원래대로 되돌리거나 `setup`을 다시 실행하세요. |
| 알림이 안 옴 | ① `testNtfy` 실행해 보기 ② 폰의 ntfy 토픽 이름 확인 ③ Apps Script 왼쪽 ⏰ **트리거**에 `checkReminders`(15분마다)가 있는지 확인 — 없으면 `setup` 다시 실행 |
| "죄송합니다. 현재 파일을 열 수 없습니다" | 주소가 잘렸거나 배포가 바뀌었어요. `showLinks`로 주소를 다시 확인하세요. |
